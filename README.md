## ⚡ 一键体验（Mock / 零密钥）

```bash
# Enterprise RAG（fake/echo，无 Key）
git clone https://github.com/Hou-mingyuan/enterprise-rag && cd enterprise-rag && docker compose up -d --build

# AI Service Agent（Mock LLM）
git clone https://github.com/Hou-mingyuan/ai-service-agent && cd ai-service-agent && docker compose up -d --build

# AI Assistant SDK（零密钥 smoke）
git clone https://github.com/Hou-mingyuan/ai-assistant-sdk && cd ai-assistant-sdk
docker compose up -d --build && node scripts/smoke-zero-key.mjs http://localhost:8080/ai-assistant
```
